# Пирамида метрик — агент-продуктолог

Плагин для Claude Code: агент строит 5-уровневую пирамиду метрик продукта, подбирает North Star Metric через job-to-be-done и валидирует результат по чек-листу из 21 пункта.

## Что такое пирамида метрик

| # | Уровень | Суть |
|---|---------|------|
| 1 | Бизнес | Revenue, MAU — цели компании и инвесторов |
| 2 | Маржинальность | LTV, CAC, ARPU — юнит-экономика |
| 3 | Лояльность | Retention, NPS, K-factor — возврат и рекомендации |
| 4 | Ценность (NSM) | Ключевая ценность продукта для клиента |
| 5 | Качество | Помогает / мешает пользователю — баги, трение |

Два направления работы:

- **Сверху вниз (декомпозиция):** бизнес-цель разбивается на управляемые метрики нижних уровней.
- **Снизу вверх (правило иерархии):** инициатива не идёт в прод, если улучшает нижний уровень, но роняет верхний.

NSM подбирается через JTBD: какую проблему решает продукт, как клиент измеряет успех, какое действие в продукте лучше всего коррелирует с Retention.

## Возможности

- `/new-pyramid <бизнес-контекст>` — полный workflow построения пирамиды: чтение памяти → контекст → 5 уровней → чек-лист → Excel-артефакт и карточка проекта.
- `/review-pyramid <проект или путь к xlsx>` — аудит готовой пирамиды по всем 21 пунктам чек-листа + проверка правила иерархии.
- `/extract-lesson <суть фидбека>` — сохранение урока из фидбека в Knowledge Graph Memory со связями к проекту, уровню пирамиды и ревьюеру.
- Модельный навык `metrics-pyramid` — агент применяет методологию автоматически при работе с продуктовыми метриками, NSM, unit-экономикой.
- Навык `excel` — оформление пирамиды в .xlsx (openpyxl + pandas).

## Установка

### Как плагин Claude Code

```
/plugin marketplace add OlegSychugov/metrics-pyramid-plugin
/plugin install metrics-pyramid@metrics-pyramid-plugin
```

### Вариант «просто skills»

Склонируйте репозиторий и скопируйте нужные навыки из `skills/` в `~/.claude/skills` (глобально) или `<проект>/.claude/skills` (для одного проекта). Slash-команды при этом станут обычными навыками — вызывайте их по имени (`new-pyramid`, `review-pyramid`, `extract-lesson`).

## MCP-серверы

Плагин подключает три сервера через `.mcp.json`:

| Сервер | Что делает | Настройка |
|---|---|---|
| `memory` | Knowledge Graph для накопления уроков | Работает из коробки (npx) |
| `tavily` | Поиск индустриальных бенчмарков | Получите ключ на [tavily.com](https://tavily.com) и экспортируйте переменную `TAVILY_API_KEY` |
| `metric-notes-grep` | Literal-поиск по Markdown-базе методологии | Один раз создать venv — см. ниже |

`metric-notes-grep` (Windows, из корня репозитория; подробнее — `tools/metric-notes-grep/README.md`):

```powershell
python -m venv tools\metric-notes-grep\.venv
& "tools\metric-notes-grep\.venv\Scripts\python.exe" -m pip install --upgrade pip
& "tools\metric-notes-grep\.venv\Scripts\python.exe" -m pip install "mcp[cli]>=1.0,<2.0"
```

Для `tavily` ключ задаётся через переменную окружения — сам ключ нигде в репозитории не хранится:

```powershell
setx TAVILY_API_KEY "<ваш ключ>"
```

## Структура репозитория

```
.claude-plugin/plugin.json  — манифест плагина
.mcp.json                   — MCP-серверы (memory, tavily, metric-notes-grep)
AGENTS.md                   — роль агента и структура проекта
SOUL.md                     — принципы и тон агента
skills/
  metrics-pyramid/          — модельный навык (SKILL / REFERENCE / EXAMPLES / CHECKS / MEMORY)
  new-pyramid/              — построение пирамиды для нового продукта
  review-pyramid/           — ревью готовой пирамиды
  extract-lesson/           — сохранение урока в память
  excel/                    — работа с Excel
METHODOLOGY/index/          — выжимки: концепции, глоссарий, эвристики, формулы
EVALS/                      — регрессионные брифы (6 кейсов) и инструкция прогона
tools/metric-notes-grep/    — локальный MCP-сервер поиска по Markdown
PROJECTS/_template/         — шаблон карточки проекта
```

Папки пользовательских проектов (`PROJECTS/*`, кроме `_template`) и результаты прогонов (`EVALS/runs/`) в git не попадают — см. `.gitignore`.

## EVALS — регрессия

После изменений в `skills/metrics-pyramid/SKILL.md`, `CHECKS.md`, `MEMORY.md` или `heuristics.md` прогоните 2–3 кейса из `EVALS/briefs.md` (6 брифов с эталонами) по инструкции из `EVALS/run.md`. Регрессия: NSM не попал в допустимые варианты, пропущена обязательная эвристика, CHECKS < 17/21.

## Философия

Каждая метрика — это ответ на вопрос «что ценно для клиента?», а не строчка в отчёте. Одна North Star Metric лучше десяти метрик: она отражает ключевую ценность продукта, и команда понимает, какой рычаг нужно потянуть, чтобы бизнес рос.

Правило иерархии священно: никогда не предлагаем инициативу, которая улучшает нижний уровень пирамиды, но роняет верхний. Метрики без порогов — не сигнал; абсолюты без нормировки — не метрики.

Агент учится на обратной связи: каждое исправление сохраняется как урок в Knowledge Graph и делает следующие пирамиды точнее. Подробно — `SOUL.md`.

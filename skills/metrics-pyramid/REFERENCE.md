# Справочник метрик пирамиды

## Содержание
- Уровень 1: Бизнес-метрики
- Уровень 2: Маржинальность (Unit-экономика)
- Уровень 3: Лояльность
- Уровень 4: Ценность (NSM / PVM)
- Уровень 5: Качество (PQM)

---

## Уровень 1: Бизнес-метрики

Верхний уровень. Отражает главные цели компании. Важен для инвесторов, фаундеров, топ-менеджмента.

### Валовые показатели

| Метрика | Описание | Когда использовать |
|---------|----------|--------------------|
| **Revenue** | Общая выручка за период | Любой продукт с монетизацией |
| **ARR** | Annual Recurring Revenue — годовая выручка с подписок | SAAS, подписочные модели |
| **MRR** | Monthly Recurring Revenue | SAAS, подписки (оперативный контроль) |
| **MAU** | Monthly Active Users — уникальные пользователи за месяц | Продукты без монетизации, социальные сети, контент |
| **DAU** | Daily Active Users | Продукты с ежедневным использованием |
| **GMV** | Gross Merchandise Volume — объём транзакций | Маркетплейсы, агрегаторы |
| **Market Share** | Доля рынка | Зрелые рынки с известными конкурентами |

### Нефинансовые показатели (ранняя стадия)

Для продуктов без модели монетизации: рост аудитории, вовлечённость, retention — то, на что смотрят инвесторы.

### Амбиции фаундера

Бизнес-метрика может отражать личную миссию основателя. Важно понять этот драйвер — он определяет стратегию. Например: «Zero Sales Business» —愿景 компании, где продажи полностью автоматизированы.

## Уровень 2: Маржинальность (Unit-экономика)

Декомпозиция бизнес-метрик на показатели прибыльности в расчёте на одного клиента.

### Формула уровня

```
Маржа = LTV − CAC − OPEX_per_user
```

### LTV (Lifetime Value)

Пожизненная ценность клиента — накопительная маржа (или доход) от клиента за всё время.

- **Фактический:** считается по завершённым когортам
- **Прогнозный:** LTV = ARPU × Average Lifetime (или ARPU / Churn Rate)
- Рассчитывается по когортам
- Математически декомпозируется: LTV = Retention × Средний чек
- Здоровый LTV/CAC ≥ 3

### CAC (Customer Acquisition Cost)

Стоимость привлечения одного платящего клиента.

- CAC = Marketing Costs / New Paying Customers
- Или: CAC = CPL / C1 (Cost per Lead / Конверсия в первую покупку)
- Разовая издержка

### ARPU (Average Revenue Per User)

Средний доход на одного активного пользователя = Revenue / Active Users.

### ARPPU (Average Revenue Per Paying User)

Средний доход на одного платящего = Revenue / Paying Users. Точнее отражает ценность для платящего сегмента.

### OPEX per User

Операционные расходы на одного пользователя (серверы, поддержка, контент).

## Уровень 3: Лояльность

Декомпозиция маржинальности. Лояльность = Возвращаемость + Референтность.

### Retention Rate

% пользователей, вернувшихся через N дней после первого использования.

- Считается по когортам: Retention D1, D7, D30, D90
- Ключевой предсказатель LTV и долгосрочного роста
- Низкий Retention → проблема с PMF (Product-Market Fit)

### Churn Rate

% пользователей, прекративших использование за период. Обратная сторона Retention.

- Churn = 1 − Retention
- Показывает «дыру в ведре»

### Sticky Factor (DAU/MAU)

Насколько регулярно пользователи возвращаются в течение месяца.

- DAU/MAU: 20%+ — хорошо, 50%+ — отлично (мессенджеры, соцсети)
- Используется для продуктов с ежедневным использованием

### K-factor (Виральность)

Сколько новых пользователей приводит один существующий.

- K > 1 — экспоненциальный рост
- Каналы: реферальные ссылки, шеринг, «сарафанное радио»

### NPS (Net Promoter Score)

Готовность рекомендовать продукт (опрос «С какой вероятностью вы порекомендуете?..»).

- NPS = % Promoters (9-10) − % Detractors (0-6)
- Диапазон: −100 до +100
- Требует регулярных опросов

### C2 (Конверсия во 2-ю покупку)

% клиентов, совершивших повторную покупку или продливших подписку.

- Отличается от Retention: измеряет оплату, а не использование
- Управление Retention (использованием) помогает предсказывать C2 (оплату)

## Уровень 4: Ценность (NSM / PVM)

Клиентоцентричный уровень. Отражает, насколько хорошо продукт решает основную проблему пользователя.

### NSM (North Star Metric)

Единственная метрика, отражающая ключевую ценность для клиента.

**Свойства хорошей NSM:**
- Измерима и управляема
- Коррелирует с Retention и Revenue
- Понятна всей команде
- Клиентоцентрична

**Типы NSM по продукту:**

| Тип продукта | Пример NSM |
|-------------|------------|
| Доставка / такси | Скорость подачи (time-to-delivery) |
| Маркетплейс | Заказов на активного пользователя |
| SAAS / продуктивность | Задач завершено / контент создан |
| Финтех | Экономия клиента (money saved) |
| Образование | Уроков завершено / навыков acquired |
| Контент / медиа | Время качественного потребления |

### PVM (Product Value Metrics)

Набор метрик ценности, если NSM одна недостаточно описывает продукт. Но цель — свести к одной NSM.

## Уровень 5: Качество (PQM)

Самый детальный уровень. Декомпозиция ценности на «помогает» и «мешает».

### Метрики, помогающие пользователю

Факторы, способствующие успешному решению задачи:

- % завершённых ключевых сценариев (conversion funnel completion)
- Время до первого успеха (time to first value)
- Использование подсказок / онбординга
- Доля пользователей, достигших «aha-moment»

### Метрики, мешающие пользователю

Барьеры и проблемы на пути пользователя:

- Баги на пользователя / на сессию
- % пользователей, столкнувшихся с критической ошибкой
- Время недоступности сервиса (downtime)
- Время ответа (latency, page load time)
- Галлюцинации ИИ / ошибочные рекомендации
- Тикеты в поддержку на 1000 пользователей

### Эволюция метрик

Метрики качества могут «переезжать» на уровень ценности, когда становятся отраслевым стандартом. Например, скорость доставки для маркетплейса была метрикой качества, а стала NSM.

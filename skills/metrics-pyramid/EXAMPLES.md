# Примеры пирамид метрик для разных продуктов

## Содержание
- ИИ-ассистент для B2B продаж
- SAAS-платформа для аналитики
- Маркетплейс услуг
- Мобильное приложение (B2C)
- Продукт на ранней стадии (без монетизации)

---

## Пример 1: ИИ-ассистент для B2B продаж

**Контекст:** Solo-founder, B2B SAAS, модель подписки.

```
┌─────────────────────────────────────────────────┐
│  УРОВЕНЬ 1: БИЗНЕС                              │
│  Revenue: $50K MRR → $200K MRR                  │
│  Амбиция фаундера: «Zero Sales Business»         │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 2: МАРЖИНАЛЬНОСТЬ                      │
│  LTV = $5 000  CAC = $800  LTV/CAC = 6.25       │
│  ARPU = $150/мес                                │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 3: ЛОЯЛЬНОСТЬ                          │
│  Sticky Factor (DAU/MAU) = 60%                  │
│  Retention D30 = 70%                            │
│  C2 (продление подписки) = 85%                  │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 4: ЦЕННОСТЬ (NSM)                      │
│  NSM: Time per Sales action → 0                 │
│  (время от идеи до совершения продажи клиентом) │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 5: КАЧЕСТВО                            │
│  + % успешных автосгенерированных писем = 92%   │
│  + Скорость ответа ИИ < 2 сек                   │
│  − Галлюцинации ИИ на 100 запросов = 3          │
│  − Время от заявки до фичи = 5 дней             │
└─────────────────────────────────────────────────┘
```

**Job-to-be-done:** «Когда мне нужно вести B2B продажи, я хочу автоматизировать рутину, чтобы тратить время на стратегию, а не на повторяющиеся действия.»

**Связь уровней:**
- Time per Sales action ↓ → Sticky Factor ↑ → LTV ↑ → MRR ↑

## Пример 2: SAAS-платформа для аналитики

**Контекст:** B2B SAAS, тарифы по числу пользователей, рост.

```
┌─────────────────────────────────────────────────┐
│  УРОВЕНЬ 1: БИЗНЕС                              │
│  ARR: $2M → $5M                                 │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 2: МАРЖИНАЛЬНОСТЬ                      │
│  LTV = $12 000  CAC = $2 500  LTV/CAC = 4.8     │
│  ARPU = $500/мес  ARPPU = $800/мес              │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 3: ЛОЯЛЬНОСТЬ                          │
│  NPS = +45                                      │
│  Retention D30 = 80%                            │
│  Churn = 3%/мес                                 │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 4: ЦЕННОСТЬ (NSM)                      │
│  NSM: Dashboards created per user per week      │
│  = 2.5 → 5.0                                    │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 5: КАЧЕСТВО                            │
│  + Запросов построено без ошибок = 98%          │
│  + Время загрузки дашборда < 1.5 сек            │
│  − Баги на пользователя = 0.1                   │
└─────────────────────────────────────────────────┘
```

**Связь уровней:**
- Dashboards/week ↑ → пользователь видит ценность → NPS ↑ → Churn ↓ → LTV ↑ → ARR ↑

## Пример 3: Маркетплейс услуг

**Контекст:** B2C-маркетплейс, комиссия с транзакций, рост.

```
┌─────────────────────────────────────────────────┐
│  УРОВЕНЬ 1: БИЗНЕС                              │
│  GMV: ₽500M → ₽2B   Revenue (комиссия): ₽50M    │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 2: МАРЖИНАЛЬНОСТЬ                      │
│  Take Rate = 10%  Contribution Margin = 40%     │
│  CAC (клиент) = ₽500  CAC (исполнитель) = ₽1000 │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 3: ЛОЯЛЬНОСТЬ                          │
│  C2 (повторный заказ) = 45%                     │
│  K-factor = 0.6                                 │
│  Retention D30 = 20%                            │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 4: ЦЕННОСТЬ (NSM)                      │
│  NSM: Orders per active user / month            │
│  = 1.2 → 2.5                                    │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 5: КАЧЕСТВО                            │
│  + % заказов выполнено в срок = 88%             │
│  + Время отклика исполнителя < 15 мин           │
│  − % отменённых заказов = 8%                    │
│  − Жалобы на 1000 заказов = 12                  │
└─────────────────────────────────────────────────┘
```

**Связь уровней:**
- Orders/month ↑ → C2 ↑ → GMV ↑; K-factor ↑ → CAC ↓ → Margin ↑

## Пример 4: Мобильное приложение (B2C)

**Контекст:** Фитнес-приложение, freemium, подписка за премиум.

```
┌─────────────────────────────────────────────────┐
│  УРОВЕНЬ 1: БИЗНЕС                              │
│  MAU: 500K → 2M   Подписчики Premium: 50K       │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 2: МАРЖИНАЛЬНОСТЬ                      │
│  ARPU = $0.50  ARPPU = $8/мес                   │
│  Конверсия в Premium = 10%                       │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 3: ЛОЯЛЬНОСТЬ                          │
│  Sticky Factor (DAU/MAU) = 25%                  │
│  Retention D7 = 40%  D30 = 15%                  │
│  K-factor = 0.3                                 │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 4: ЦЕННОСТЬ (NSM)                      │
│  NSM: Тренировок завершено / user / week        │
│  = 1.5 → 3.0                                    │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 5: КАЧЕСТВО                            │
│  + % завершённых тренировок = 70%               │
│  + Персонализация: % подходящих рекомендаций=85%│
│  − Крэши на сессию = 0.01%                      │
│  − Время загрузки экрана > 3 сек = 5%           │
└─────────────────────────────────────────────────┘
```

**Связь уровней:**
- Тренировок/week ↑ → Sticky Factor ↑ → Retention ↑ → Конверсия в Premium ↑ → Revenue ↑

## Пример 5: Продукт на ранней стадии (без монетизации)

**Контекст:** MVP, модель монетизации не определена, фокус на привлечении аудитории.

```
┌─────────────────────────────────────────────────┐
│  УРОВЕНЬ 1: БИЗНЕС                              │
│  Registrations: 1 000 → 10 000                  │
│  (инвестиционная метрика — рост аудитории)       │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 2: МАРЖИНАЛЬНОСТЬ                      │
│  Не применим — монетизация не подключена         │
│  Контроль: Cost per Registration = $2           │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 3: ЛОЯЛЬНОСТЬ                          │
│  Retention D1 = 50%  D7 = 20%                   │
│  Sticky Factor (DAU/MAU) = 15%                  │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 4: ЦЕННОСТЬ (NSM)                      │
│  NSM: Время, сэкономленное пользователем        │
│  (self-reported + поведенческие прокси)          │
├─────────────────────────────────────────────────┤
│  УРОВЕНЬ 5: КАЧЕСТВО                            │
│  + % пользователей, достигших «aha-moment» = 40%│
│  − % сессий < 30 сек (bounce rate) = 35%        │
└─────────────────────────────────────────────────┘
```

**Красный флаг:** Retention D7 = 20% — продукт может не решать проблему (проблема с PMF).

## Типичные ошибки при построении пирамиды

1. **Vanity metrics на верхнем уровне** — метрики, которые выглядят хорошо, но не отражают здоровье бизнеса (общее число регистраций без Retention).
2. **Отсутствие связи между уровнями** — метрики лояльности не коррелируют с NSM.
3. **Слишком много NSM** — должна быть одна. Если нужно несколько — уточните ценность.
4. **Игнорирование правила иерархии** — оптимизация качества в ущерб ценности.
5. **Бизнес-центричная NSM** — NSM должна отражать ценность для клиента, а не Revenue.

# Извлечь урок из фидбека

## Шаг 1. Сформулировать урок

Из фидбека пользователя сформулируй урок. Каждое наблюдение начинается с даты `ГГГГ-ММ-ДД`:

- **Проблема:** что было не так.
- **Решение:** что делать вместо (конкретное действие «делать X вместо Y», а не «X — это плохо»).
- **Контекст:** тип продукта, стадия, источник фидбека.
- **Применимость:** уровни пирамиды, типы продуктов.

Имя сущности: `Урок: <короткая формулировка>`.

## Шаг 2. Проверить дубли

`memory_search_nodes` по ключевым словам урока.

Похожий урок уже есть? → `memory_add_observations` к существующему. Новый не создавай.

## Шаг 3. Создать сущность

`memory_create_entities`:

```json
{
  "entities": [{
    "name": "Урок: <короткая формулировка>",
    "entityType": "MetricsLesson",
    "observations": [
      "ГГГГ-ММ-ДД: <проблема>",
      "Решение: <что делать вместо>",
      "Контекст: <тип продукта, источник фидбека>",
      "Применимость: <уровни пирамиды>"
    ]
  }]
}
```

## Шаг 4. Создать связи

`memory_create_relations`:

- Урок → Проект (`получен из`)
- Урок → Уровень пирамиды (`применяется на`) — один или несколько
- Урок → Ревьюер (`автор фидбека`) — если фидбек дал эксперт

Урок без связей не сохраняется.

## Шаг 5. Обновить карточку проекта

Добавь урок в раздел «Применённые уроки» соответствующего `PROJECTS/<X>/PROJECT.md` в формате `[[Урок: …]]`.

Шаблоны сущностей, правила формулировки и анти-паттерны — в [`../metrics-pyramid/MEMORY.md`](../metrics-pyramid/MEMORY.md).

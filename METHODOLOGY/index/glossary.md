# Глоссарий

Плоский словарь терминов. Для подробностей — `skills/metrics-pyramid/REFERENCE.md`.

| Термин | Определение | Источник |
|--------|-------------|----------|
| **MAU** | Monthly Active Users — уникальные пользователи за месяц | Ключевые метрики продукта |
| **DAU** | Daily Active Users — уникальные пользователи за день | Ключевые метрики продукта |
| **WAU** | Weekly Active Users — уникальные пользователи за неделю | Ключевые метрики продукта |
| **MEU** | Monthly Engaged Users — вовлечённые активные пользователи за месяц | Ключевые метрики продукта |
| **NSM** | North Star Metric — одна клиентоцентричная метрика ценности (Уровень 4) | NSM Метрики |
| **OMTM** | One Metric That Matters — главная метрика стадии (Lean Analytics); не путать с NSM | NSM Метрики |
| **LTV** | Lifetime Value — накопительная маржа от клиента за всё время | Как рассчитать LTV |
| **CAC** | Customer Acquisition Cost — стоимость привлечения одного покупателя | Как рассчитать Unit-экономику |
| **CPL** | Cost Per Lead — стоимость привлечения одного лида | Как рассчитать Unit-экономику |
| **ARPU** | Average Revenue Per User — средний доход с пользователя за период | Ключевые метрики продукта |
| **ARPPU** | Average Revenue Per Paying User — средний доход с платящего пользователя | Ключевые метрики продукта |
| **C1** | Конверсия в первую покупку (Number of first-time buyers / Number of visitors) | Ключевые метрики продукта |
| **C2** | Конверсия во вторую покупку (повторные покупки / первая покупка) | Ключевые метрики продукта |
| **Retention** | % пользователей, возвращающихся в продукт через N-период (по когортам) | Ключевые метрики продукта |
| **Churn Rate** | % оттока пользователей за период (обратная сторона Retention) | Экономика продукта и unit-экономика |
| **NPS** | Net Promoter Score = (% промоутеров − % критиков) × 100% | Шпаргалка формулы метрик |
| **Sticky Factor** | DAU/MAU — индикатор ежедневной вовлечённости | Ключевые метрики продукта |
| **K-factor** | Виральный коэффициент — сарафанное радио / приведённые клиенты | NSM Метрики |
| **OPEX** | Operating Expenses — операционные издержки (постоянные + разовые) | Как рассчитать Unit-экономику |
| **Contribution Margin** | price per unit − variable cost per sale | Юнит-экономика |
| **Lifetime** | Средняя продолжительность жизни клиента в продукте | Как рассчитать LTV |
| **Cohort** | Группа пользователей по дате захода в продукт | Как рассчитать LTV |
| **RFM** | Recency-Frequency-Monetary — сегментация для unit-экономики | Как рассчитать Unit-экономику |
| **PMF** | Product-Market Fit — продукт решает реальную боль рынка | Запись защит курсовых работ |
| **JTBD** | Jobs-To-Be-Done — задача клиента, которую решает продукт | NSM Метрики |
| **CJM** | Customer Journey Map | Клиентоцентричность и деньги |
| **LJM** | Life Journey Map (Tony Fadell) | Клиентоцентричность и деньги |
| **Market Share** | Доля рынка — ключевая метрика для красных рынков | Поведенческая экономика. Метрики стартапов |
